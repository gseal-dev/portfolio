# Jesiel Gavina | Portfolio

A minimalist, black and white static portfolio website for a Business Analytics graduate.

## Tech Stack
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)
- Docker (for containerization)
- Nginx (for serving)

## Getting Started

### Prerequisites
- [Docker](https://docs.docker.com/get-docker/)
- [Docker Compose](https://docs.docker.com/compose/install/)

### Running with Docker
To build and run the portfolio locally using Docker:

1. Open your terminal in the project directory.
2. Run the following command:
   ```bash
   docker-compose up -d --build
   ```
3. Open your browser and navigate to `http://localhost:8080`.

### Local Development
Alternatively, you can just open `index.html` directly in your browser.
